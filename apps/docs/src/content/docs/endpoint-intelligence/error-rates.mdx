# Error Rates

Learn how error rates works within Endpoint Intelligence and how to apply it safely in Tellann.

## Overview

**Error Rates** is part of aggregated request volume, latency, error, and session-correlation signals for backend endpoints. It gives teams a shared way to describe what the application actually did and which evidence supports a quality conclusion.

## Mental model

Read this topic in the sequence Connect → Observe → Demonstrate → Model → Analyze → Investigate → Act. The same event can contribute to a session, a state transition, a workflow, a graph edge, coverage, and a report without those artifacts becoming interchangeable.

## How to use it

Choose the application and environment first, then narrow the evidence by workflow, session, time, endpoint, or event type. Use labels and metadata to make the captured behavior explainable to someone who did not run the original scenario.

## Interpretation

Interpret the result together with its source events and collection conditions. Observed means Tellann received evidence for the behavior; it does not independently prove that the behavior is correct, secure, accessible, or complete.

## Limitations and responsibilities

Customers remain responsible for instrumentation scope, lawful data collection, credential handling, privacy rules, and decisions made from the evidence. Tellann masks and isolates data according to configuration, but cannot infer every domain-specific sensitive field.
